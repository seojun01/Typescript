
### \@ts-check
- 자바스크립트 파일에서 오류를 활성화하려면 // @ts-check를 .js 파일의 첫 번째 줄에 추가하여 Typescript가 오류를 발생시키도록 함.
- Typescript는 여러 오류를 제공할 수 있음.
- 이러한 오류를 무시하고 싶다면 // @ts-ignore | @ts-expect-error를 추가하여 특정 줄의 오류를 무시할 수 있음.

### JSDoc
- JSDoc 주석을 사용하여 Javascript 파일에 type 정보를 제공할 수 있음.
- (자바스크립트 파일에서 타입 정보를 제공할 수 있음.)
	1. 주석을 달기 전에 tsconfig.json 에서 allowJs: true 넣어주기
	2. 주석 다는 법
		1. Js 파일에 주석달기
		2. // @ts-check
		3. /* Initializes the project \n @param {object} config \n @param {boolean} config.debug ... \*/
