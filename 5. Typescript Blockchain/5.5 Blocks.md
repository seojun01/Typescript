
### ts-node
- ts-node는 Node.js용 Typescript 실행 엔진 및 REPL임.
- JIT는 Typescript를 Javascript로 변환하므로 사전 컴파일 없이 Node.js에서 Typescript를 직접 실행할 수 있음.
	- npm i -D ts-node

### nodemon
- npm i -D nodemon

### esModuleInterop
- CommonJS 모듈을 ES6모듈 코드베이스로 가져오려고 할 때 발생하는 문제를 해결함.
- ES6 모듈 사양을 준수하여 CommonJS 모듈을 정상적으로 가져올 수 있게 해줌.
