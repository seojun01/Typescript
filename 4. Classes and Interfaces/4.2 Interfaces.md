
### Type & Interface
```typescript
type Team = "blue" | "yellow" | "red";
type Health = 1 | 5 | 10;

// type 선언시 타입의 특정값들로 제한할 수 있다.
type Player = {
	nuckName: string,
	team: Team,
	health: Health,
}

// Interface : object의 모양을 지정해주기위한 용도.
// type이 interface보다 범위가 넓음.
interface Player {
	nuckName: string,
	team: Team,
	health: Health
}

const player1: Player {
	nickName: "hello",
	team: "red",
	health: 10
}
```
- Type의 용도
	1. 특정 값이나 객체의 값에 대한 타입을 지정해줄 수 있다.
	2. Type alias(타입에 대한 별명)을 만들어줄 수 있다.
	3. 타입을 특정한 값을 가지도록 제한할 수 있다.

- 타입과 인터페이스의 차이점은 type 키워드는 interface 키워드에 비해서 좀 더 활용할 수 있는 것이 많다는 것임.
- 즉, interface는 오로지 객체의 형태를 타입스크립트에게 설명해주기 위한 용도로만 사용됨.
- interface는 상속의 개념을 사용할 수 있음. => 문법 구조가 객체지향 프로그래밍의 개념을 활용
- interface는 속성(Property)들을 '축적' 시킬 수 있음.
