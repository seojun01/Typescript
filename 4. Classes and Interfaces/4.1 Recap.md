
```typescript
type Words = {
	[key: string]: string;  // 객체의 property에 대해 모르지만 타입만을 알 때 유용.
};

class Dict {
	private words: Words;
	constructor() {
		this.words = {};
	}
	add(word: Word) {  // word는 Word 클래스의 인스턴스 타입, 클래스도 타입으로 사용 가능하다.
		if(this.words[word.term] === undefined) {
			this.words[word.term] = word.def;
		}
	}
	def(term: string) {
		return this.words[term];
	}
}

class Word {
	constructor(
		public term: string,
		public deff: string
	) {}
}

const kimchi = new Word("kimchi", "한국의 음식");
const pizza = new Word("pizza", "미국의 음식");
const dict = new Dict();

dict.add(kimchi);
dict.add(pizza);
```
- `[key: string]: string` 형식은 객체의 property에 대해 모르지만 타입만을 알 때 유용하다.
- 클래스도 타입으로 사용 가능하다.
