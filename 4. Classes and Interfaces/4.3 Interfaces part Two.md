
### Implements
```typescript
interface Pingable {
	ping(): void;
}

// Sonar 클래스는 Pingable 인터페이스를 implements했기 때문에 Pingable가 가진 ping 메서드를 구현해줘야 함.
class Sonar implements Pingable {
	ping() {
		console.log("ping");
	}
}
```
- implements을 사용하여 클래스가 특정 인터페이스를 충족하는지 확인할 수 있음.
- 클래스를 올바르게 구현하지 못하면 오류가 발생함.
- implements 절은 클래스가 인터페이스 유형으로 처리될 수 있는지 확인하는 것임.
- 클래스의 유형이나 메서드는 전혀 변경하지 않음.
- 또한 클래스는 여러 인터페이스를 구현할 수도 있음.
