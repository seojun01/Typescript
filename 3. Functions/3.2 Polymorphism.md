
### Polymorphism (다형성)
- Poly : many, several, much, multi 등과 같은 뜻
- Morphos : form, structure 등과 같은 뜻
- Poly + Morphos = 여러 다른 구조

### Concrete type
- number, boolean, string, void 등 지금까지 배운 타입

### Generic type
- 타입의 Placeholder라고 표현할 수 있음

```typescript
type SuperPrint = <T>(a: T[]) => T

const superPrint: SuperPrint = (a) => a[0]

const a = superPrint([1,2,3])
const b = superPrint([true, false, true])
const c = superPrint(["a", "b"])
const d = superPrint([1,2,"a","b", true])
```

### Conclusion
- 제네릭은 선언 시점이 아니라 생성 시점에 타입을 명시하여 하나의 타입만이 아닌 다양한 타입을 사용할 수 있도록 하는 기법이다.
1. T의 의미
	1. T는 "Type"의 약자로, 제네릭 타입 변수로 자주 사용됨.
	2. 제네릭 함수, 인터페이스, 클래스 등에서 특정 타입을 나타낼 때 사용되며, 단일 타입을 나타낼 때 주로 사용함.
2. V의 의미
	1. V는 "Value"의 약자로, 제네릭 타입이 두 개 이상일 때 보조적으로 사용됨.
	2. 다른 타입과 구별하기 위해 두 번째, 세 번째 타입 변수로 자주 사용됨.
3. 관례적인 이름들
	1. 제네릭 타입 변수의 이름은 자유롭게 지정할 수 있지만, 가독성을 위해 자주 사용하는 약어가 존재.
		1. T | Type(단일 타입) | 일반적인 제네릭 타입 변수에 사용
		2. K | Key | 객체의 키 타입을 나타낼 때 사용
		3. V | Value | 객체의 값 타입을 나타낼 때 사용
		4. E | Element | 배열이나 컬렉션의 요소 타입을 나타낼 때 사용
