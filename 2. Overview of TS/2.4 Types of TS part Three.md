
### Unknown
```typescript
let a: unknown

if(typeof a === 'number') {
	let b = a + 1 // Error
} else if(typeof a === 'string') {
	let b = a.toUpperCase()
}
```
- unknown 타입은 모든 값을 나타냄.
- any 타입과 비슷하지만 any 보다 unknown이 더 안전함.

### Void
```typescript
function hello() {
	console.log('x')
}
const a = hello()
a.toUpperCase() // Error
```
- 아무것도 return 하지 않는 함수에서 반환 자료형

### Never
```typescript
function hello(): never {
	throw new Error("err")
	// return "a" => impossible
}
```
- 함수가 return 하지 않을 때

```typescript
function temp(name: string | number): never {
	if(typeof name === "string") {
		name
	} else if(typeof name === "number") {
		name
	} else {
		name
	}
}
```
- if 안에서는 string 형의 name 반환
- else if 안에서는 number 형의 name 반환
- else 안에서는 never 형의 name 반환
- => 제대로 인자가 전달되었다면 else로 올 수 없음
