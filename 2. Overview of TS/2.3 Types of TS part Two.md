
### Readonly
```typescript
type Player = {
	readonly name: string,
	age?: number
}
const playerMaker = (name: string): Player => ({name})

const nico = playerMaker("nico")
nico.name = "a" // Error, name is readonly
------------------------------------------------------------
const numbers: readonly number[] = [1, 2, 3, 4]
numbers.push(2) // Error, numbers is readonly
```
- readonly가 있으면 최초 선언 후 수정 불가
- => 불변성 부여
- => 하지만, 자바스크립트에서는 그냥 배열

### Tuple
```typescript
const Player: [string, number, boolean] = ["nico", 10, false]
const Player: readonly[string, number, boolean] = ["test", 2, true]
```
- 정해진 개수와 순서에 따라 배열 선언
- readonly도 사용 가능 => readonly\[...] 형태

###  undefined, null, any
- any : 아무 타입, 꼭 필요할 때만 사용
- undefined : 선언 X 할당 X
	- age?: number 여기서 ? 는 number | undefined 의 축약
- null : 선언 O 할당 X
