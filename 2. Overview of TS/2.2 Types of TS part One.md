
### Types
- 배열 : 자료형[]
- 숫자 : number
- 문자열 : string
- 논리 : boolean

### Optional
```typescript
  const player: {
	  name: string,
	  age?: number
  } = {
	  name: "test"
  }
```
- ?를 붙이면 optional

### Alias
```typescript
type Player = {
	name: string,
	age?: number
}

const player: Player = {
	name: "test"
}
```
- `type`으로 Player 타입 생성 (type 생성할 때는 첫 번째 글자 대문자)
- player의 타입은 Player 타입
```typescript
type Player = {
	name: string,
	age?: number
}

function playerMaker(name: string): Player {
	return {
		name // or name: name으로도 사용 가능
	}
}
const playerMakerArrow = (name: string): Player => ({ name })

const nico  playerMaker("nico")
nico.age = 12
```
- 함수에서는 위와 같이 사용
- playerMaker함수의 인자로 name을 string으로 받고, 함수의 반환 값은 Player 타입으로 반환
- Arrow Function에서도 동일
- playerMaker로 생성한 nico는 Player 타입으로 반환한 함수로 만들어졌기 때문에 age 수정 가능
